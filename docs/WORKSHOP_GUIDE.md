# 当前操作：应用内经典地图与可视化搭建

在「我的地图」选「经典地宫 · 0.8.0 / 新版角色」或「低语森林 · 0.8.0 / 新版角色」→「开始游戏」。角色使用衣柜已保存的搭配，进入后直接开始。

WASD / 点击地面移动、J攻击、K技能、E跳跃、空格冲刺、P暂停、M全图、R检查点重试。顶部「角色衣柜」暂停关卡，可查看/保存装备；保存应用搭配，取消保留原搭配，关闭后在原位置继续。「我的地图」退出本局返回列表。

经典地宫仍为算术→摆锤→熔火→独木桥，按0.8.0原通关条件推进。装备外观和动画来自新版，战斗伤害/范围保持原守卫数值；本轮没有额外背包、掉落或装备属性。旧随从与敌人保留原素材。经典布局固定，不能用房屋工坊重排；可编辑的自建地图仍按下面步骤使用。经典记录独立保存classic-native-records.json，原存档不删除。

1. 进入地图编辑，点击顶部「搭建房屋 / M」。
2. 单击要扩建的房间，金色边缘表示选中；点击某一侧的「＋」。
3. 选择宽、高、房型、朝向，点「添加房屋」。门与开关自动生成。取消不留下空房间；空间不足会提示，可换大小或方向。
4. 在总览中拖动房间，靠近其他房间边缘会吸附；松手提交连接。红色代表重叠，松手不会修改地图。Esc或松手到画布外取消。
5. 已连接房间整组移动。只重排一间：先选它，点右侧「解除本房间拼接」，再拖到目标房间边缘。自动开关会随解除连接移除，手动开关需重新关联。⌘Z可撤销。
6. 双击房间编辑内部。最后仍需设置终点门与开关，试玩通过后加入游玩列表。

# 房间工坊操作指南 · 019

本指南对应原生工坊 0.4.0；项目总说明见 [README](../README.md)。双击交付目录中的 `Thornbound Workshop.app`，无需安装 Godot。默认进入地图主界面。

## 从零搭建一张可玩的地图

1. 点击「新建空白地图」。也可以选内置「四关拼接地图」→「编辑选中地图」，在已有结构上修改。
2. 左侧「尺寸 / 房型…」选择宽 10–30 格、高 10–24 格，以及矩形、L形、T形、十字形与旋转角度。每格 32 像素。已有拼接时，先在右侧解除拼接再改尺寸；裁掉的对象可以撤销恢复。
3. 用「出生点」安排玩家起点；「墙壁」「地板」改变内部道路。「选择」工具点击对象后，右侧显示该对象属性。右键擦除，⌘Z 撤销，⇧⌘Z 重做。
4. 点击「＋ 新房间」创建下一关。在右侧选择要拼接的目标房间、右/下/左/上方向与侧向偏移，点击「预览拼接」再「应用拼接」。系统自动对齐墙面、放置配对隔板门及出口开关。M 查看整体地图，再点击某个房间可进入编辑。
5. 在最后一关的平直外墙上放「隔板门」——手动放置的门默认通往终点。门内附近放「开关」。用选择工具点击开关，在右侧确认它关联正确的门。不要放在墙角，也不要堵住门内的落脚点。
6. 展开「机关选择 ▾ / 收起」，选机关后点击空地。选择框内容较多时可滚动左栏；再次点标题即可收起。总计 12 类，包括地刺、炸弹和本次新增的 10 类。
7. 点击「保存草稿」。需要单独文件时使用「另存为…」。未完成的地图也能保存草稿；退出前务必保存。重开后使用「继续当前草稿 → 载入…」恢复自己的 JSON。
8. 点击「▶ 从第1关试玩」。先修复提示的未连接房间、无开关、缺少终点、路径碰墙等问题，再测试是否真的能通关。校验只证明静态连通，不保证所有机关组合都容易或一定可通过。
9. Esc 返回编辑，点击「加入游玩列表」，输入名称并确认。此操作把当前地图的一份快照保存到本机地图库。
10. 点击「主界面」，选中刚加入的地图，点击「开始游戏」。这就是正式游玩入口：编辑工具隐藏，完整地图从第一关开始。下次打开软件仍能选择这些地图。

## 四个地刺逐个调整时间

先在四个不同格子放好地刺，然后切换「选择」。依次点击四个地刺，在右侧设置：

| 地刺 | 启动延迟 | 重复周期 | 生效时间 |
|---|---:|---:|---:|
| 第 1 个 | 0 秒 | 3 秒 | 0.6 秒 |
| 第 2 个 | 0.5 秒 | 3 秒 | 0.6 秒 |
| 第 3 个 | 1 秒 | 3 秒 | 0.6 秒 |
| 第 4 个 | 1.5 秒 | 3 秒 | 0.6 秒 |

这些参数属于各自实例；选中第二个修改，不会改变其他三个。示例已放在「机关实验室」地图的上方一排。

**时间含义：**本房间首次进入时开始计时；延迟结束后进入重复周期。每个周期先安全，最后“生效时间”长的阶段危险。例如延迟 0、周期 3、生效 0.6，第一次危险是第 2.4–3 秒；第二个延迟 0.5 的第一次危险是第 2.9–3.5 秒。离开房间后暂停该房间时钟，返回继续；R 重试清零本房间时钟。M 总览与操作指南会暂停游玩。

延迟允许 0–120 秒，周期 0.4–30 秒，生效时间至少 0.1 秒且不能超过周期。炸弹单独设置延迟及靠近后引信（0.3–30 秒）。塌落平台的“承重时间”从踩上开始计算，周期表示从触发到恢复的时间。弹簧的周期同时限制重复触发。

## 机关区别

| 类型 | 行为与摆放注意 |
|---|---|
| 地刺 | 周期伸出，危险阶段触碰致命 |
| 炸弹 | 进入 80px 范围后点燃；86px 爆炸范围；开门不会熄灭引信 |
| 旋转刺阵 | 原地近身周期危险 |
| 移动锯轮 | 沿方向往返；可设距离，运行轨迹不能碰墙 |
| 摆动刺球 | 链条支点周围摆动；只有球伤人，整个摆动范围需留空 |
| 伸缩长矛 | 沿指定方向形成危险区，范围不能穿墙 |
| 箭塔 | 每周期一支箭，墙和关闭的门会挡箭 |
| 火焰箱 | 沿方向喷火，可调作用距离 |
| 风扇 | 吹动玩家，可搭配地刺；不能把人吹穿墙 |
| 落石 | 落下前有警示圈，生效阶段砸中致命 |
| 塌落平台 | 踩上开始计时，超过承重时间还停留会坠落；随后恢复 |
| 弹簧 | 沿方向弹出玩家，短暂腾空可越过伤害，不能穿墙 |

实验室是机关功能展示，主要出口道路在上方；不是经过难度平衡的挑战关卡。按下 F 后门需要约 0.65 秒完全收起，真正走入门洞才会进入下一关。下一关机关从进入时开始，不提前运行。

## 保存、地图列表与副本

- 「保存草稿/另存为」：存编辑用 JSON，允许未完成地图；不会自动改变主界面已经加入的正式地图。
- 「加入游玩列表」：校验后存一份可玩快照；编辑主界面选中的自建地图后再次加入，会更新该地图，旧版保留 `.bak`。改名称不会自动创建副本。
- 要新建另一张作品：从内置模板开始或新建空白地图；要复制已有作品：先另存 JSON，再通过「载入」读取它，然后加入列表，会创建独立条目。
- 外部地图：进入编辑 → 载入 JSON → 试玩 → 加入游玩列表。
- 正式游戏返回主界面会恢复游戏前正在编辑的草稿。没有自动保存：退出前仍要保存草稿。
- 默认草稿：`~/Library/Application Support/Godot/app_userdata/THORNBOUND · 房间工坊/rooms-v2.json`。
- 正式地图库：同目录下 `maps/`，每张地图独立 JSON。软件升级不需要搬动这些文件。备份时可复制整个用户数据目录。
- 损坏或不能通过可玩校验的地图不会出现在列表中，原文件保留；可到编辑器「载入」查看错误。当前列表未提供删除/排序/缩略图管理。

## 操作键与边界

WASD/方向键移动，F 按附近开关，R 重试当前房间，M 总览并暂停。试玩中 Esc 返回编辑；正式游玩中 Esc 返回主界面。房间名称输入后按 Enter 提交。输入框获得焦点时不触发移动。

此版本是本地房间工坊，不是把原网页五关战斗系统全部移植完毕；原网页游戏保留。角色衣柜已经支持模块化外观和动作，后续背包/战斗见 [装备方案](EQUIPMENT_PLAN.md)。地图“正式游玩”指本机游玩入口，并非联网发布或公开发行。

## 角色衣柜

主界面或编辑/游玩顶部点击「角色衣柜」。选择头盔、护甲、主手和副手；下方可预览待机、行走、武器动作、倒地。保存并用于游玩后，所有地图使用这套搭配，重开软件仍保留；取消不改变现有角色。战斧和长矛占双手，不能同时拿盾。长裤/靴子固定。当前没有装备掉落与攻击伤害，武器动作是预览。

外观单独保存于用户数据目录appearance-v1.json。游玩中打开衣柜会暂停机关。作者、原素材链接与许可可在衣柜内查看，源PNG和逐文件署名表位于源码art/lpc目录。
