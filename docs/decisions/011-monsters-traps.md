# 011：新包替换与复杂度
按用户最新需求替换敌人，选5种独立轮廓和完整动画：00/01/02/03/09；第09种接替旧熔岩火元素角色，保留此前驻留熔岩规则，不再使用生成火焰图。另保留史莱姆。森林没有永久熔岩，因此炎魔只在第四关出现，其余4种新怪与史莱姆用于森林。
时间解锁依次0/6/14/22/30/38秒，兼顾约50秒完整关卡流程与更长停留的增长。重试保留总时间/新种类，恢复角色与机关；密度上限受控。普通怪第二关两边、第三关东边进入，使后解锁敌人能及时接触玩家。
