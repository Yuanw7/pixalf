# 013：木头人回廊（第3关）

用户要求新增一关"鱿鱼游戏木头人"：boss 巨像、红灯期间移动即被激光击中、房间里若干喷火机关"从上到下"排布，玩法是在空档停留、不能停在火焰上。用户选择把它**插在第2关与第3关之间**，boss 用**素材库现有怪物放大**，火带按**从下到上依次喷发**。

## 世界为什么必须扩大
地牢世界原为 2240×1440，四关已占满：房间0(64–704/512–992)、房间1(768–1408/608–928)、房间2(1472–2176/512–992)、房间4(64–2176/1120–1376)，中间只剩 y992–1120 这 128px 的带子，装不下一个纵向喷火房。因此本轮：
- 世界宽度 2240 → **2880**（必须是 32 的整数倍，`COLS=WORLD_W/CELL`；2900 会让网格除不尽）。
- 第3关熔火试炼整体东移 630px 到 x2102–2806，答题板原点 1600 → 2230。
- 木头人房建成 x1500–2000 / y512–1118（500×606），正好夹在摆锤长廊与熔火试炼之间。
- 通道：主走廊东端止于 x1440 → 下行竖井(x1376–1520/y800–1118，从房间左下进入) → 房间右上出口走廊(x1968–2880/y512–576，直接压进熔火房间顶部) → 楼梯(x2102–2198/y928–1264) → 独木桥。

通道按半径 13 采样四角判定，相接的房间若只共享边线会出现一格宽的断点（可行走网格不连通）。竖井、出口走廊、楼梯都做了至少一格的重叠，`tests/level-complexity.mjs` 用真实地面点击走完全程来断言连通。

## 五关重编号
0 算术熔岩厅 → 1 摆锤长廊 → **2 木头人回廊** → 3 熔火试炼 → 4 熔岩独木桥。
- 出生点统一为 `CAMP`：`[144,752] [816,752] [1560,1080] [2150,752] [2112,BEAM_Y]`。
- 门禁：x720 仍是第1关答题门；原 x1424 门取消（房间本身已成必经之路），改为**房间出口门 x2040**（stage<3 锁）；楼梯门 x>2080 改为 stage<4 锁。
- 摆锤的 `stage` 随之调整（熔火圆摆 stage3、木梁三锤 stage4）。
- 存档：四关记录 `thornbound.trials.v2` 原样保留，五关通关写入新的 `thornbound.trials.v3`（version3, cleared5）。旧 v1/v2 都不迁移不删除。

## 木头人 boss 与红绿灯
boss 不新增美术：取素材库 `Monster01 枯木守卫`（唯一木质人形），按 3.4 倍画成占据房间上部的巨像，底部加投影。这是用户指定的做法（"从素材库里选一个放大"）。
- 周期 `绿灯3.4s → 转身预警0.6s → 红灯2.6s`；眼睛颜色即灯色（绿/琥珀/红），同时在屏幕右上角画一个与镜头无关的红绿灯，因为镜头在房间底部时巨像会在画面外。
- 红灯期间**只判定主角**：以红灯开始时的位置为锚，发生超过 12px 的位移就锁定 0.35 秒后发射激光（26 伤害 + 强击退），每次红灯最多一发。
- **被推不算移动**：`pushTime>0` 或同伴贴身推挤时重新取锚，避免被火焰击退后又被激光追击；主角倒下也不判定。
- 随从在红灯与转身期间同样站住（只保留不需要位移的攻击），不替玩家决定成败。
- boss 是规则而非可击杀目标，攻击不结算伤害，与摆锤同类。

## 火带
四条横向火带 y=650/770/890/1010，横跨房间全宽（x1500–2000），每条一个 `flameband`：休止2.7s → 预警0.7s（槽口变亮+地面警示线）→ 喷发0.9s（火舌平铺 + 伤害14 + 沿带法线轻推）。
- 相位差 0.6 秒，且**偏移随 y 增大**，所以最下面那条先亮、火浪自下而上推进；这正是用户选的"从下到上依次喷发"。
- 空档即两条火带之间约 88px 的通道：入场高度 y800（在 770 与 890 之间）、y830/y950 空档、顶部 y<634 通往右上出口。测试断言"站在火带上会烧、站在空档不掉血、跳跃可越"。
- 公平性沿用 0.8.0 的不变量：机关伤害/风压区域不得覆盖出生点与题板数字格中心（房间两处新的出生点也纳入检查）。

## 木梁阶段的既有脆弱点（本轮暴露）
插入新关改变了到达木梁的相位，0.7.0 起就存在的相位脆弱点因此不再靠运气通过：木梁只有 24px 宽，旋转锤的切向击退在穿越点是纯竖直方向，**任何一次命中都会把人推入熔岩**。本轮不再改这个既有机制（ADR-012 已记录），改为：
- 木梁东端加一块 72×72 实体登陆台（`BEAM_LAND`），让入口附近的击退可以恢复；
- 楼梯锯轮从 y1204 上移到 y1160，离开木梁落脚区；
- 自动验收在第5关**允许使用游戏自带的检查点重试**，并逐次记录（0.8.0 及以前是要求首次通过）。这是本轮唯一被放宽的验收强度，其余四关仍要求首次通过，理由与数据都写在验收报告里。
