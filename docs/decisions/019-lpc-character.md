# ADR019：采用现成LPC模块化人物

用户选择更换现成模块化角色体系，取代018装备计划中“拆分原士兵”的路线。

- 美术：Universal LPC成人男性基底，固定上游提交58ce1aa479e4df32845a73a5d0afc221c3a893c2，52张原始PNG/19层。正文中的原士兵43帧不再作为新装备管线基础。
- 插件：Godot素材库LPCAnimatedSprite2D，固定abe214da0a71c55a295d42ef7ea64f11dcc69769，原代码不改。bake_lpc.gd实际调用插件生成SpriteFrames；自有适配器限制为已验证动作和体型。
- 运行：character_catalog统一装备规则和帧时钟，outfit_panel提供四方向预览/动作/保存。绘制接入现有Canvas坐标，暂不替换原房间碰撞系统。外观不改变玩家碰撞尺寸。
- UI：继续已有CompleteUI橄榄绿按钮与中文字体。新人物采用LPC轮廓和比例；不是宣称与原Tiny士兵逐像素一致。
- 数据：user://appearance-v1.json独立保存，schema1+rig=lpc_male_v1，地图schema不改。预览深拷贝，取消不变，保存原子替换并备份。
- 当前能力：头盔2款或无、护甲2款、长剑/双手战斧/双手长矛或空手、圆盾或无；固定长裤/靴子，36种合法组合。攻击只在衣柜预览，不宣称已有战斗伤害、背包、掉落或装备属性。
- 许可：保留上游署名和每文件许可；优先选择已列出的OGA-BY 3.0，否则CC-BY-SA 3.0。原始PNG随源码可访问，游戏内有作者与许可入口。插件MIT独立。
