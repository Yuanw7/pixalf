# ADR-008 跳跃与熔岩独木桥
用户授权：史莱姆轻推玩家、移除陷阱轨迹、增加窄木棍熔岩和旋转锤关卡、玩家跳跃。

新增第四关接原三关后，扩展现有世界下层，避免覆盖旧关卡；保留当前关检查点。主角用E跳跃，空格仍冲刺，避免旧操作冲突。设24像素窄梁、96像素断口，跳跃具备真实落点判定，地面冲刺不能绕过断口。旋转锤只显示物体和连杆，删除预画弧线。

轻推约24像素，限定史莱姆成功命中，与受击无敌和墙体碰撞统一。跳跃不是全程无敌；达到20像素高度后规避近战/锤头，落地仍检查熔岩；不穿墙/门，不豁免算术落脚判定。

随从自动跟跳和避险，避免AI精度导致玩家任务失败。四关结果写新trials.v2，保留旧三关trials.v1。独立场景截图明确标识测试夹具，正常输入全流程另行验证，不混为真人全程通关。
