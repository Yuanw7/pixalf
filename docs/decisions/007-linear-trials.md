# ADR-007 地牢改线性三关
用户授权地牢闯关、三秒算术熔岩、大摆锤、持续战斗及一主角一随从。“随处”按随从实现，森林暂保留生存玩法。

选择同图三段串联，门禁锁定顺序，按当前关重试，避免长距离重复。算术两题/摆锤/算术三题加摆锤构成明确递进。数字每题洗牌，仅1—9，每题3秒；错误格落下，正确格暂留；主角失败直接重试。随从优先跟随并避险，不替玩家选择答案。

暂停冻结所有机关；地牢移除150秒胜利条件。继续复用已核实独立角色素材，机关以代码绘制像素效果，不引入额外资源或网络依赖。战斗上限收至55以适配双人和有限通道。检查点不持久化，完整通关使用独立版本化记录。

地牢药水按每关入口/出口分散，不再要求旧自由地图400像素统一间距；森林保持六区400像素标准。当前目标变化登记CR-007，旧构建保留。
