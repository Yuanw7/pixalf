# ADR018：机关实例参数与本地地图快照

沿用Godot工坊与schema2，新增字段由目录给出缺省值；旧地刺保持原周期比例。每个对象独立delay/period/active/fuse/direction/travel，运行状态单独存储，未进入房间不计时。

可玩地图与草稿分开：地图库每张独立JSON、原子替换与bak；没有网络发布。大厅内置四关与机关实验室，用户地图扫描加载。正式游玩暂存草稿，返回恢复。

新增机关复用原TrapAndWeapon动画，不用图标冒充可穿戴动画。CompleteUI统一边框，Raven负责通用图标；不强行混用全部新UI包。装备系统本次仅计划分层人物与锚点，避免烘焙刀盾加新武器的重复外观。
