# ADR-004 双地图、密集入侵与补给争夺

2026-10-07；依据用户明确新增地图、怪物密度、多样性与道具需求。

保留森林，新增RF_Catacombs地宫，使用统一世界尺寸与两套可通行几何。出发界面同时选图和领队。支持点击地面移动，以便主动争夺补给。

现有可用敌人原图家族为史莱姆、血怪、兽人、恶魔、士兵；通过颜色、体型、速度及远近程差异形成十种变体，不宣称十套独立素材。带Premium水印的图不接入。

增强分批外部入场与祭坛增援，设置156活动上限。降低单怪伤害以适配密集战斗；道具为全队增益，鼓励主动移动。回血55、武力60%/18秒、速度45%/16秒，24秒重生；同类续时、不叠倍率，满血不消耗。用缓存寻路/变色减少密集场景开销。

新地图原包附Szadi art公共许可，可使用与修改但不得转售素材包；Icons未附明确许可，保留来源，限当前持有者本地原型。既有素材限制继续适用。

保存记录增加可选last.map，不改变v2时间单位；旧记录兼容，旧构建保留用于回退。用户对平衡和视觉认可仍待实际试玩。
