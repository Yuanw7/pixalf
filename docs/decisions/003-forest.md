# ADR-003 · 扩展世界与时间驱动遭遇
状态：已采用。授权：用户要求扩图、更多素材怪物、选角、林外渐进出现、不显示波次和敌人数量。
替代：001中“单屏地图、三波血怪”在0.2.0失效；原文保留为历史。

决定：2240×1440世界＋960×600跟随镜头，以河流/桥/遗迹/林道形成通行选择；共享反向BFS支持队友与敌人绕障碍。小地图和M总览帮助辨认复杂地形。
选角只决定初始领队，另外两位仍自动协战；局内保留切换。卡片使用原角色图、职业与技能说明，选中状态明确。
敌人直接用原素材史莱姆、血怪、兽人、恶魔；后两者为敌对游荡单位，红色地面圈与敌方生命条区别于伙伴，不改变原角色像素。骷髅以及water1带Premium文字，继续不用；水面、桥、帐篷为代码绘制。
以150秒夜晚推进替代三波计数胜利，保留结算重开闭环。界面只呈现夜色与无数字进度条；不显示敌人数量。开局宽松，种类与间隔渐变，活跃上限保护性能。出生点在世界外，固定入口通路防止生成到树干内部。
时长战绩使用v2独立键；v1单位不同，保留而不迁移，回退0.1.0仍可读取原战绩。
限制：单个确定性地图、数字键盘操作、共享寻路场优先跟随领队，不是精确团队战术；未增加经营/装备/联网。
回退：核对builds/0.1.0清单，直接打开其game/index.html，原包和v1保存保持完整。
