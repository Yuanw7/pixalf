# ADR021：经典地图采用同窗口内置运行器

用户纠正020的外部网页入口，要求在我的地图直接选中并玩0.8.0。列表新增runtime=classic080条目，不伪造Godot房间JSON；普通地图继续原运行路径。

使用自有macOS GDExtension与系统WKWebView，挂载到Godot现有NSWindow。原版四文件不改，保留Canvas玩法、角色、敌人和四关；无需浏览器跳转或HTTP服务。顶部原生返回按钮卸载运行视图，下面仍是原地图列表，草稿与衣柜不变。经典地图编辑按钮禁用。此决策替代020的外部浏览器入口。

独立原子记录文件避免构建路径变化影响进度；不迁移外部浏览器存储。其余平台尚无运行器，明确报错；目前交付为macOS应用。底层为内嵌原运行逻辑，不宣称已重写Godot原生战斗或可用房屋编辑器改经典关卡。
