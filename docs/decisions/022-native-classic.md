# ADR022：原关卡规则模块 + Godot原生绘制 + LPC主角

用户要求新版角色进入旧版关卡并纳入新版系统，021内置WebView原版画面不能满足此要求。

将0.8.0的关卡/战斗计算保留为JavaScriptCore规则模块：没有页面、DOM引擎、WebView、网络或JS计时器；Godot固定步长推进计算，统一处理输入。脚本生成器仅移除浏览器异步图像初始化，追加Canvas绘图指令记录器与输入/状态接口。旧原始四文件不修改，所有关卡坐标、陷阱周期、题目/门条件、跳跃/击退和敌人/随从逻辑原样复用。此为混合规则实现，不宣称将全部计算重写为GDScript。

Godot CanvasItem执行原绘图指令，SubViewport缓存背景，原图尺寸提取而非重绘。主角sprite替换为LPC图层指令，与character_catalog共用装备资源、四方向动作及衣柜。攻击动画受真实attack状态驱动，伤害仍由原版规则结算；本轮不以换武器改变伤害/范围，保持既有平衡。旧随从和怪物保留原素材。

legacy_game.gd提供原生HUD、输入、暂停、重试、全图、衣柜和返回；衣柜冻结计算并在关闭后同步已保存外观。经典地图分为地宫和森林列表入口，当前布局为固定规则地图，不能用房屋工坊重排。普通schema2地图不变。经典记录独立classic-native-records.json，不改旧存档。

旧WebView源保留为历史实现与底层扩展公共入口，但主界面经典项不再创建或调用WebView。当前JavaScriptCore原生扩展仅Mac，arm64/x86_64通用。
