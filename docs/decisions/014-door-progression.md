# ADR-014 · 横向木头人、腹部门与统一按钮出口

日期：2026-10-09；版本：0.9.0 重做，接替 ADR-013 的木头人布局和自动出口判定。

用户要求横向木头人房间、木头人腹部打开通往下一关的门、所有地牢关卡用按钮确认通关，并使用 Canvas 保持风格。

原话包含“从左到右”和“木头人在最左边”两处相反方向。本轮提出二选一澄清并告知默认采用左进右出；截至实现时尚未收到方向回复，因此木头人位于右侧终点。

## 决策
- 在原世界内将木头人房改为640×352，四道火带竖向横挡路线，火浪左→右。固定相机呈现全房；守门人用 Canvas 木纹像素轮廓，腹部双扇门共用普通石门逻辑。
- F 为交互键，E 保留跳跃；也支持靠近后点击按钮。远距点击仅寻路，不自动替玩家确认。
- ready、activated、open 分开：完成前置挑战只允许交互，按按钮才算本关完成，动画结束才解除门碰撞，走入门才切换下一关。
- 出口统一定位下一检查点，消除旧代码散落的跨坐标自动跳关；与腹部门的空间连接一致。
- 开门后本关机关停止判定，木头人不再因玩家入门而发射激光。保留 .85秒开门动画和输入明确反馈。
- 算术解题、红绿灯规则、木梁跳跃等基础玩法保留；第五关也使用按钮再入门结算。
- 版本按用户所说的0.9.0重做保留，构建输出新的时间戳快照，旧0.9.0不覆盖。

## 验证
门的专项测试覆盖远距、未解题、腾空、暂停、动画碰撞、入门切关、重试、最终结算；完整机器人通过普通输入操作五个按钮。浏览器单独验证闭门/开门画面和真实 F/点击输入。详见 reports/014-acceptance.md。
