## 可观察验收行为
1. 第3关房间 500×606，右上出口；进入点在左下角（y≈1080），出口在右上（y≈540），必须自下而上穿过四道火带。
2. 红绿灯：绿灯可走，转身 0.6 秒预警，红灯必须站住；红灯期间位移超过 12px 会被激光击中（26 伤害 + 击退），被击退不算移动。随从同样站住。
3. 四条横向火带 y=650/770/890/1010，自下而上依次喷发；站在火带上受伤，站在两条之间的空档安全，跳跃可越过。
4. 世界与通道：从第2关走廊 → 下行竖井 → 房间 → 右上出口走廊 → 熔火试炼，全程可走通（真实点击寻路验证）。
5. 通关写入 `thornbound.trials.v3`（cleared=5），旧 v2/v1 保留。
6. 木梁东端有实体登陆台，楼梯锯轮离开落脚区。
