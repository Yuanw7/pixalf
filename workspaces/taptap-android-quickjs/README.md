## 构建与验证

在本目录执行：

```sh
python3 scripts/build.py macos
node tests/compare.mjs
```

运行Godot全套回归（GODOT_BIN是可执行文件路径）：

```sh
"$GODOT_BIN" --headless --editor --path game --import
"$GODOT_BIN" --headless --path game -- --self-test
```

Android原生库入口：

```sh
ANDROID_NDK_HOME=/你的/ndk/目录 python3 scripts/build.py android
```

Android目标为arm64/API 24；原生库链接配置考虑16KB页对齐，实际Android工具链和设备兼容性仍需验证。此命令只生成原生库，不生成APK。后续需要安装Android SDK/NDK、匹配Godot导出模板，设置发布签名、APK导出预设，再进行真机验证。

## 设计边界

Godot使用FileAccess读取打包的rules.js，将源码交给QuickJS；不依赖真实文件系统路径，因此为APK/PCK资源读取预留了通路。图片改用Godot资源加载。每个ClassicRuntime对象持有独立QuickJS实例，关闭/重开释放旧状态。未向JavaScript暴露文件、网络或系统执行接口。设置128MiB内存限制与单次命令5秒中断保护；它们是原型保护值，不是手机性能验收指标。

原规则文件保持字节一致。差分测试的固定随机数与跳关注入仅在测试进程中生成，不写入游戏文件。
