# 本实验版的更新与交付约定

用户明确要求每次更新后启动位置一致。

- 所有本实验版改动在此工作区内完成，保留原项目与历史版本。
- 日常唯一启动入口保持为本目录的 `启动实验版.command`，不得改名或迁入带版本号/日期的新目录。
- 启动器默认使用本目录 `runtime/Godot`，游戏固定为 `game/`；不得重新依赖带时间戳的历史 builds。
- 后续更新直接更新本工作区；历史备份和 reports 可带版本号，但交付链接始终指向固定启动文件。
- 保留 `THORNBOUND-QuickJS-Lab` 用户存档目录；不能因更新清空玩家地图、草稿或角色搭配。
- 更新涉及启动方式时同步维护 `00-从这里开始.txt` 和 README.md，并运行启动器 --check。实际游戏行为变化仍需相应测试。
- 最终回复给出同一个启动文件链接，简要说明更新内容与使用入口。
