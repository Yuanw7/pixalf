【荆棘盟约 · 固定启动说明】

一、启动游戏
1. 打开 Finder（访达），按 Command + Shift + G。
2. 粘贴下面的文件夹路径并回车：
   /Users/kafufu/pixalf/workspaces/taptap-android-quickjs
3. 双击「启动实验版.command」。
4. 会先弹出终端窗口并准备资源，请等到游戏窗口出现。
5. 启动页点击「开始游戏」→ 选择地图 → 点击「开始游戏」。
   新挑战示例：挑战试炼 · 木头人与数字快答。
   旧版关卡：经典地宫 · 0.8.0 / 新版角色。

二、编辑地图
启动页点击「创意工坊」。右侧「房间挑战」可选木头人或数字快答。
保存草稿 → 从第1关试玩 → 返回编辑 → 加入游玩列表 → 主界面 → 开始游戏。
「多人游戏」目前是开发中说明入口，尚不能联机。

三、每次更新的位置约定
始终双击同一个「启动实验版.command」，不需要找带日期或版本号的新文件夹。
更新前先保存工坊草稿、退出游戏；更新完成后重新双击启动文件。
固定入口：/Users/kafufu/pixalf/workspaces/taptap-android-quickjs/启动实验版.command
游戏文件：本目录 game/
引擎文件：本目录 runtime/Godot（不再依赖旧版 builds 文件夹）
更新记录：README.md 与 reports/；历史归档不作为日常启动入口。
存档：~/Library/Application Support/THORNBOUND-QuickJS-Lab
更新时保留该存档目录；不要把整个实验工作区单独拆散或只移动启动脚本。
可把本工作区拖到 Finder 侧边栏收藏，以后从收藏进入。

如果双击打开的是文本编辑器：右键启动文件 → 打开方式 → 终端。
如果启动没有出现游戏窗口：保留终端中的报错，资源准备日志在 reports/import.log。

四、027 新武器与动画
开始游戏 → 经典地宫 / 低语森林 → 角色衣柜 → 主手武器「地宫飞刀 · 远程」→ 保存并用于游玩。
J 攻击；飞刀自动朝可见敌人投掷，墙和门会挡住；长剑、战斧、长矛有不同打击表现。
按最终通关按钮后播放庆祝，再出现结算。怪物倒地后留下短时遗骸。
工坊 J 可以试挥或投掷，但工坊暂无战斗敌人；伤害/遗骸请在经典地图体验。

五、030 当前按键与画面
空格：跳跃（保留 E 作为兼容按键）。经典地图 Shift：冲刺。
J：普通攻击。K：爆发技能，原有 7 秒冷却；命中有短刀光、闪白碎片及约 45 毫秒停顿。
F：开关/确认通关。R：重试。M：地图。经典地图 P：暂停。
工坊空格也可跳跃，K 可预览技能效果；实际伤害请进入经典地图体验。
主角铠甲改为钢灰色，仍保留换装；经典地宫与工坊采用 0x72 的褐色地砖、墙沿、旗帜、壁灯和石柱。
既有关卡路线、机关位置、地图与装备存档保留。退出旧游戏窗口，再从同一个启动文件打开即可使用更新。

六、031 大型机关房与多选
创意工坊 → 右侧房间挑战 → 木头人机关房 / 数字地砖。至少18×12矩形；应用模板清理内部，门/开关保留，可撤销。
我的地图新增「大型机关房 · 木头人＋数字地砖」可直接开始。
选择工具：Shift点击多选；选择同类机关；⌘/Ctrl+A全选机关。右侧统一延迟、周期、生效时间；留空不改，一次撤销。
木头人：绿灯走/红灯停，停在纵向火带间隙。数字地砖：3秒内站到正确数字，默认2题。通过后按F开出口。
多人玩法仅方案，详见MULTIPLAYER_PLAN.md，尚不能联机。
