# 032：全图撤离倒计时

目标：在工坊地图属性中选择是否限时撤离，建立“越晚越危险、及时汇合”的规则基础。核心流程：编辑整图时限 → 保存/发布 → 开始整局计时 → 过房间 → 截止前按最终开关撤离。

使用：固定启动实验版 → 创意工坊 → 右侧“整图撤离倒计时” → 开启撤离时限 → 设置秒数（10–3600，默认600）。这是一张地图共用的设置，在任何房间修改都会影响整张地图；不是每间房各自倒计时。旧地图缺省关闭，保存/载入/加入游玩列表均带上设置。

开局计时，跨房间不中断。M、衣柜、帮助/失焦沿用既有暂停行为；单人死亡后冻结以便重试。普通R检查点重试不补时；超时后R重开整局、回第一间房并恢复全部房间机关。胜利锁定时冻结计时，最后开关不能在零秒后强行通关。该倒计时仅用于工坊地图，固定布局的经典战斗地图仍沿用原计时/刷怪逻辑。

UI直接使用用户素材包Complete_UI_Essential_Pack_Free的Flat主题：Frame01a、Bar02a、BarFill01a和BarFill01d。原图复制到game/art/ui，未重新生成/修改原图；来源与哈希在reports/032/ui-sources.json。显示MM:SS、剩余进度条，最后30秒红色。实际渲染截图timer-editor.png、timer-play.png（后者使用25秒余量的明确视觉测试设置）。

状态所有权：地图extraction保存enabled/seconds，extraction_timer.gd校验/格式化；main.gd的run_elapsed与extraction_expired唯一拥有本局运行状态，tick推进，开关交互再次检查截止条件。没有写入中途存档，不改变schema2和既有挑战类型。

范围与限制：本次新增可运行倒计时；现有经典战斗随时间增加怪物的逻辑保留。工坊自建房间还没有普通战斗敌人，新增多人增怪/宝石/联网不在本次实现，见MULTIPLAYER_PLAN.md的032补充。用户难度认可与安卓真机待验证。

验证：24条新专项含默认关闭/存档回读/非法值/撤销/暂停/跨房/死亡重试/超时整局重开/截止前后最终开关/胜利冻结；1754条完整工坊检查通过。源码与前版本备份、测试日志、图片及SHA256清单放在reports/032。固定启动入口不变，玩家地图/装备目录不清理。
