# 027 · 战斗素材

`throwing_knife.png` 原样复制自用户素材包 `Free-Melee-Weapon-Pixel-Icons-for-Cyberpunk.zip / 1 Icons / Icon28_24.png`，作者/来源 Craftpix。原包有 40 个近战武器图标，没有枪械；本项目选用绿色刃器图标，定义为「翠刃飞刀」投掷武器。原许可链接保留在 License.txt。

用途：衣柜选择后的角色持握层、真实飞行弹体。通过 Canvas 旋转纹理、点采样缩放；不把图标当成完整角色动画。

近战弧光、长矛直刺、发射亮光、拖尾、命中碎光、胜利徽记和碎屑由 combat_visual.gd 绘制。视频只作动作节奏/配色参考，没有截取参考游戏画面作为游戏素材。敌人残留复用现有 Monster / Slime 图集，旋转倒地并压低亮度；图集本身不改写。
