## 本地房间工坊（Godot · 迭代022）

支持房间边缘加号添加、拖动吸附连接、可变房型、真实空间拼接、12类机关独立计时与多地图主界面。最新交付目录记录在 [工坊构建日志](reports/022-build.log)，测试和优化方案见 [022验收](reports/022-acceptance.md)。双击目录内 `Thornbound Workshop.app` 即可启动，无需另装 Godot；默认进入地图列表。详细步骤见 [操作指南](docs/WORKSHOP_GUIDE.md)，模块化换装实现与后续路线见 [装备方案](docs/EQUIPMENT_PLAN.md)。

- **角色衣柜**：已改用现成LPC模块化人物与LPCAnimatedSprite2D导入插件。头盔、护甲、剑/斧/矛、圆盾可组合，36种合法搭配；四方向预览、武器动作和本机保存，所有地图生效。游玩中的人物按方向播放行走/待机/倒地。当前是外观与动作版本，背包、伤害与掉落尚未实现。
- **机关**：素材按独立机关类别共14类；工坊原有地刺/炸弹之外新增10类，合计12类。左侧选择框可折叠、滚动。选择单个机关后调整延迟、周期、生效时间，以及适用的方向/距离/引信；四个地刺可以设不同延迟而互不影响。内置「机关实验室」提供12类机关及四个错峰地刺。
- **正式游玩**：保存草稿 → 从第一关试玩 → 返回编辑 → 加入游玩列表并命名 → 主界面选地图 → 开始游戏。每张地图存独立JSON，重开仍能选择。编辑自建地图后再次加入会更新原作品并留备份；正式游戏结束返回主界面恢复原编辑草稿。
- **素材整理**：13包各有README，见 [素材清点](docs/assets/018-materials.md)。新CompleteUI边框与Raven图标已经用于本地界面；武器图标不等同于可穿戴动画。

- **大小与形状**：左侧“尺寸 / 房型…”选择宽10–30格、高10–24格，矩形/L形/T形/十字形，0/90/180/270°朝向。每格32px；显示自动适配，不改变物理尺寸。已连接房间先“解除本房间拼接”再调整；裁掉的对象有数量提示，可以撤销。
- **房间拼接**：右侧选择目标房间、右/下/左/上方向和侧向偏移。先预览，再应用；自动对齐共用墙段，生成配对隔板门和开关。偏移正数对左右拼接表示向下，对上下拼接表示向右。移动目标时，与目标相连的后续房间一起移动；重叠、无可用墙段或入口被堵时拒绝修改。
- **编辑**：选择地板、墙壁、出生点、门、开关或机关后点击/拖动画布；右键擦除。手动放置的门为终点，跨房间门由拼接生成。选择对象可设置开关关联及机关时间。改名后按Enter；⌘Z撤销、⇧⌘Z重做。M切换地图总览，编辑时点击总览房间进入编辑。可新增房间，最多32间。
- **保存**：默认 `~/Library/Application Support/Godot/app_userdata/THORNBOUND · 房间工坊/rooms-v2.json`；另存为/载入支持自选JSON。覆盖前保留`.bak`，坏文件不替换布局。载入内置示例后保存会写用户目录，不改应用包。退出前请保存，重开后用“载入”恢复。
- **旧文件**：兼容016的schema 1，迁移到schema 2后保留原数据；旧门仍显示为“旧版传送连接”，解除后重新拼接即可获得空间对齐的门洞。旧文件不会在读取时被覆盖。
- **试玩**：从第1关开始，WASD/方向键移动、F开关、R从本次入口重试、M地图并暂停、Esc编辑。穿门从目标对应门内出现，已打开的入口可返回；未进入的房间机关不计时，试玩不改布局。启动前检查门配对、入口落脚点、静态道路、开关及终点可达性。

四关地图可单独载入 [four-rooms.json](workshop/maps/four-rooms.json)：18×12矩形石厅 → 18×16 L形引信房 → 22×14 T形地刺厅 → 18×18十字终厅。路线右→下→左→下方终点，四种房型均使用工坊同一套生成/拼接函数构建，非单独写死的传送示例。

源码入口 `workshop/project.godot`；`main.gd`处理界面/试玩，`map_model.gd`处理房型/拼接/存档校验，`trap_catalog.gd`/`trap_runtime.gd`处理机关，`map_library.gd`处理本机地图库；`tests.gd`/`tests018.gd`为回归。Godot 4.7.2 命令行：`Godot --headless --path workshop -- --self-test`；`Godot --headless --path workshop --script res://export_map.gd`重建示例JSON；`python3 scripts/build-workshop.py /path/to/Godot.app`生成自带引擎的macOS应用、地图、测试报告、源码和清单。

限制：四种预设房型，尚不支持自由多边形/鼠标拖拽移动房间；未迁移原版战斗、跳跃、随从和木头人规则。当前是编辑与空间连接原型，非完成难度打磨的四关正式游戏。仅本机macOS验证；自带官方Godot通用二进制，未做正式签名/公证发行。

## 启动与操作

`npm start` 后打开 http://127.0.0.1:5173 。独立交付在 `builds/`，本次快照见 [016验收](reports/016-acceptance.md)。所有图片嵌入 `assets.js`，运行时无需下载。

WASD / 方向键 / 点击地面移动；J 普攻；K 技能；空格冲刺；E 跳跃；**F 按门边按钮**（也可近距离点击按钮）；P 暂停；M 全图并暂停；R 重试本关；暂停或结果页 Esc 返回选择。

选择士兵、兽人或恶魔作为主角，一名随从自动搭配（士兵→恶魔、兽人→士兵、恶魔→兽人）。主角倒下判负，运行中不能换主角。随从伤害为对应主角的 50%。

## 每关出口的统一规则

**完成挑战 → 靠近门边按钮 → 按 F 或点击按钮 → 本关通关、门逐渐打开 → 走入门内进入下一关。**

- 算术关完成全部题目后，按钮才亮起；答完题不会自动开门。
- 摆锤、木头人、独木桥关必须走到终点按钮旁，主动按下按钮。
- 交互距离 44px；必须落地、存活且处于游玩状态。远处点击按钮只会寻路靠近，需要再按 F 或点击。
- 按下按钮后播放 0.85 秒贴墙隔板收起动画；完全打开前碰撞继续阻挡。常规机关停止伤害判定；终点炸弹引信仍继续，必须及时撤离。
- 整段门洞均可触发穿越，支持门洞边缘、跳跃和冲刺；进入门内后到达下一关入口，恢复最多 55 生命并清理上一关敌人与弹丸。最终出口也需要按钮、开门和入门，随后才结算。
- R 重试重置本关按钮、门、题目和机关状态，恢复双人生命并清理敌人、弹丸、增益；总时间保留。周期机关继续使用总游戏时间计算相位。

## 五关路线

1. **算术熔岩厅**：进入九宫格触发简单加减题。每题 3 秒，结算时必须落地站在正确格；其他地砖坠落。安全格保留 1.5 秒，两题后去右侧门边按按钮。
2. **摆锤长廊**：穿过四只错相摆锤、石柱与复合机关，按右侧出口按钮，再走入石门。
3. **木头人回廊（重做）**：640×352 横向房间，左侧入场、向右前进。木头人使用现有枯木守卫 Monster01 素材，出口是右墙上的简单隔板。绿灯 3.4 秒 → 转身预警 0.6 秒 → 红灯 2.6 秒；红灯期间主动位移超过 12px 会触发锁定激光。四道纵向火带横挡路线，从左到右依次喷发，在火带之间停留或跳过。到达终点后怪物变为素材炸弹，3.5 秒后爆炸（半径150px、80伤害）；红绿灯和火带停止，须立即按右侧开关、穿过隔板撤离。原地等候会受伤，开门不会停止引信。固定镜头同时呈现整间房和终点；左上角为紧凑红绿灯。
4. **熔火试炼**：三道算术题与复合机关，解题后按最右侧出口按钮，进入独木桥入口。
5. **熔岩独木桥**：沿 24px 宽木梁向左，跳过 80/88/96px 三处断口、避开旋转锤、塌板、炸弹和风压。走上西侧岸边后按出口按钮，进入最终石门结算。

森林仍是 150 秒生存模式。地牢没有时间到即胜利。

## 战斗、跳跃与补给

E 跳跃持续 0.9 秒、冷却 1.05 秒，最高 64px；空中可移动和攻击。高度超过约 20px 可避开有来源的攻击与机关，但不能穿墙或门。算术结算时必须落地。冲刺不能跨熔岩断口，木梁外落地会失败。

随从自动跟随、协战与跟跳；答题时避险，木头人红灯/转身时停止走动。贴身时每 0.8 秒最多轻推 6px；木梁掉落后回到主角位置，避免 AI 失足直接决定成败。

普通敌人按总游戏时间解锁：史莱姆 0 秒、骨面斥候 6 秒、铁甲兽 14 秒、沼泽巨怪 22 秒、枯木守卫 30 秒。密度随时间增加；木头人阶段不刷新普通怪。第五关熔岩炎魔 38 秒后在四个熔岩驻点出现，小幅游动、蓄力发射火球，被击杀后 8 秒再生。

血药恢复存活队员最多 55HP；武力 +60% 持续18秒；速度 +45% 持续16秒。24秒刷新，同类续时不叠倍率。

## 技术与文件

原生 HTML/CSS/JavaScript Canvas，无游戏引擎与运行时依赖。`index.html`/`style.css` 为界面，`index.js` 包含模型和渲染，`assets.js` 嵌入 43 个图片资源。守卫与炸弹复用素材库原图，隔板和开关使用简洁 Canvas 绘图，门与两端墙体共享碰撞边界，未新增外部图片。

单动画循环仅在 playing 更新模型。暂停、全图、失焦会冻结游戏时间。32px 网格和 BFS 流场用于寻路，移动以最多 8px 子步进行碰撞与落脚检查。

`localStorage`：森林 `thornbound.v2`，五关通关 `thornbound.trials.v3`；旧键保留。仅记录结果，检查点不持久保存，刷新后从第一关开始。存储被拒绝不会阻止游玩。

`npm test` 运行语法检查与十一个测试套件，包括门的交互/碰撞/暂停/重试、机关和三个主角普通输入完整闯关。模型测试不代替浏览器画面与真人体验验收。

`npm run build` 生成游戏、source.zip、START_HERE 和 SHA256 清单；同版本已有快照不覆盖，自动生成带时间的目录。回退直接打开旧包，不删除记录。
