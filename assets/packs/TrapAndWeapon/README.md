## 可用于什么

14类独立陷阱/机关资产。本次工坊使用12类：地刺、炸弹、旋转刺阵、锯轮、摆动刺球、伸缩长矛、箭塔、火焰箱、风扇、落石、塌落平台、弹簧。

## 使用边界

保留移动平台和碎裂砖为后续。弹簧/风扇属辅助机关。链条、底座、方向帧、发射物不单独计数。Root数字PNG和Rocket Bullet为弹药/武器/特效图，不虚报为独立机关。

## 素材清点

本解压目录227个文件，PNG 226张。张数不是角色/陷阱类型数，包含动画帧、预览和分辨率副本。
