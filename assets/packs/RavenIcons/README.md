# RavenIcons · 工坊应用范围

登记：迭代018 / 2026-10-10。原包：`Free - Raven Fantasy Icons.zip`。

## 可用于什么

2192个独立16×16图标，同时有32/64倍图。本次用于地图大厅、保存/帮助；武器与装备图标预留给后续装备界面。

## 使用边界

图标不是角色动作或可穿戴分层贴图；不同尺寸不能算不同道具。

## 素材清点

本解压目录6581个文件，PNG 6580张。张数不是角色/陷阱类型数，包含动画帧、预览和分辨率副本。
